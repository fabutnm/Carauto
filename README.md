# Авто-расходы

Android-приложение для учёта расходов на автомобиль. Kotlin, Jetpack Compose, Room. Данные хранятся только на устройстве.

## Возможности
- Заправки: литры, цена, пробег, расчёт расхода л/100 км (метод «до полного бака»)
- ТО и ремонт, страховка, налог, парковка, мойка, штрафы
- Напоминания по пробегу и/или дате с индикацией «скоро / просрочено»
- Статистика: итоги за период, стоимость километра, график по месяцам, график расхода топлива, разбивка по категориям

## Как открыть и запустить
1. Откройте папку проекта в Android Studio (Koala 2024.1 или новее).
2. Дождитесь синхронизации Gradle (Studio сама скачает wrapper и зависимости).
3. Запустите на устройстве или эмуляторе (Android 8.0+, minSdk 26).
4. APK: Build → Build Bundle(s) / APK(s) → Build APK(s).

## Сборка APK без компьютера (GitHub Actions)
1. Создайте репозиторий на GitHub и загрузите в него все файлы проекта (включая папку `.github`).
2. Откройте вкладку Actions — сборка запустится сама (или нажмите Run workflow).
3. Когда сборка завершится, откройте её и скачайте артефакт `CarExpenses-debug-apk` (внутри zip лежит `app-debug.apk`).
4. Распакуйте zip на телефоне, откройте APK и разрешите установку из неизвестных источников.
